# Parent Features

This document outlines all features available to the **Parent** role in the Church Management System.

## Role Overview
Parents are responsible for monitoring their children's church activities, tracking spiritual development, and staying informed about church events and announcements relevant to their families.

## Authentication & Access
- **Login Path**: `/auth/parent/login`
- **Dashboard**: `/makhdoum-parent-panel`
- **Role Identifier**: `PARENT`

## Core Features

### 1. Child Account Linking
- **Account Management**:
  - Link parent account to children's profiles
  - Send linking requests to unlinked children
  - Approve or reject linking requests from children
  - Manage multiple children from single parent account

- **Linking Process**:
  - Generate unique linking codes
  - Verify child identity through secure process
  - Maintain privacy controls for information sharing
  - Establish parental access levels and permissions

- **Link Status Tracking**:
  - Monitor pending linking requests
  - View active linked children
  - Review linking history
  - Manage linking permissions

### 2. Children's Activity Monitoring
- **Attendance Tracking**:
  - View children's Sunday School attendance records
  - Monitor church service participation
  - Check special event attendance
  - Review attendance patterns and trends

- **Points & Achievements**:
  - Monitor points earned by children
  - View achievement badges and milestones
  - Track spiritual development progress
  - Access point redemption options

- **Spiritual Development**:
  - View children's spiritual progress reports
  - Monitor class participation and engagement
  - Access teacher feedback and observations
  - Review special recognition and awards

### 3. Event & Activity Information
- **Church Events**:
  - View upcoming church events calendar
  - Access event details and requirements
  - Register children for special activities
  - Receive event reminders and updates

- **Sunday School Activities**:
  - View class schedules and topics
  - Access lesson summaries and objectives
  - Monitor homework and assignments
  - Review special project details

- **Trip & Excursion Information**:
  - View upcoming church trips and pilgrimages
  - Access trip details and requirements
  - Register children for trips
  - Track trip payments and confirmations

### 4. Communication & Notifications
- **Parent-Teacher Communication**:
  - Receive messages from Sunday School teachers
  - Send messages to teachers regarding children
  - Schedule parent-teacher meetings
  - Access teacher feedback and recommendations

- **Church Announcements**:
  - Receive church-wide announcements
  - View parent-specific communications
  - Access important church information
  - Review announcement history

- **Emergency Notifications**:
  - Receive urgent church notifications
  - Access emergency contact information
  - View safety procedures and protocols
  - Update emergency contact details

### 5. Family Information Management
- **Profile Management**:
  - Update personal contact information
  - Manage family details and structure
  - Update emergency contact information
  - Configure notification preferences

- **Privacy Settings**:
  - Control information sharing permissions
  - Set privacy levels for family data
  - Manage who can access family information
  - Configure account security settings

## User Interface Features

### Family Dashboard
- **Children Overview**: Quick view of all linked children
- **Activity Summary**: Recent activities and achievements
- **Upcoming Events**: Calendar of important dates
- **Messages Center**: New messages and notifications
- **Quick Actions**: Access to common parent tasks

### Children Profiles
- **Individual Child Cards**: Detailed information per child
- **Attendance Reports**: Visual attendance charts and statistics
- **Points Summary**: Point balance and earning history
- **Achievement Display**: Badges, certificates, and recognition
- **Teacher Feedback**: Comments and observations from teachers

### Calendar & Events
- **Family Calendar**: Combined view of all children's activities
- **Event Details**: Comprehensive information about church events
- **Registration Interface**: Easy sign-up forms for activities
- **Reminder Settings**: Customizable notification preferences
- **Filter Options**: View events by child, type, or date range

## Workflow Examples

### Linking a Child Account
1. Navigate to Account Settings → Link Child
2. Enter child's email or unique code
3. Send linking request to child
4. Wait for child approval
5. Confirm successful linking
6. Set appropriate access permissions

### Monitoring Child's Progress
1. Navigate to My Children → Select Child
2. View attendance dashboard
3. Check points and achievements
4. Review teacher feedback
5. Access spiritual development reports
6. Communicate with teachers if needed

### Registering for Events
1. Navigate to Events → Upcoming Events
2. Select event of interest
3. Review event details and requirements
4. Choose participating children
5. Complete registration form
6. Receive confirmation and updates

## Permissions & Restrictions

### Parent Can:
- View information about linked children only
- Manage own family's contact information
- Communicate with teachers of linked children
- Register linked children for church activities
- Receive relevant church communications

### Parent Cannot:
- Access information about children not linked to their account
- View other families' information or activities
- Modify church settings or administrative data
- Access sensitive church financial information
- Delete system records
