# Makhdoum (General Servant) Features

This document outlines all features available to the **Makhdoum** (General Servant) role in the Church Management System.

## Role Overview
The Makhdoum (General Servant) is a church member who serves in various capacities beyond specialized roles like visitation or Sunday School teaching. They participate in church activities, complete assigned tasks, and engage in spiritual service.

## Authentication & Access
- **Login Path**: `/auth/makhdoum/login`
- **Dashboard**: `/makhdoum-panel`
- **Role Identifier**: `SERVANT` (general type)

## Core Features

### 1. Task Management
- **Task Dashboard**:
  - View all assigned service tasks
  - Filter tasks by priority, status, or category
  - Sort tasks by due date or importance
  - Search tasks by keywords or descriptions

- **Task Details**:
  - Access complete task information and instructions
  - View task deadlines and requirements
  - Check task completion criteria
  - Review associated resources or materials

- **Task Execution**:
  - Mark tasks as completed
  - Add completion notes and observations
  - Upload supporting documents or photos
  - Request assistance if needed

### 2. Points & Recognition System
- **Points Dashboard**:
  - View current point balance and status
  - Track point accumulation over time
  - Monitor point-earning activities
  - View point redemption options

- **Service History**:
  - View comprehensive service record
  - Track tasks completed by category
  - Monitor service frequency and consistency
  - Review special recognitions received

- **Achievements & Milestones**:
  - Display earned badges and certificates
  - Track progress toward service milestones
  - View ranking among fellow servants
  - Access special achievement rewards

### 3. Schedule & Calendar
- **Personal Schedule**:
  - View upcoming service commitments
  - Access church event calendar
  - Plan availability for future tasks
  - Set personal scheduling preferences

- **Event Participation**:
  - Register for church events and activities
  - View event details and requirements
  - Track participation history
  - Receive event reminders and updates

- **Service Planning**:
  - Plan future service commitments
  - Coordinate with other servants
  - Request task assignments in preferred areas
  - Manage service calendar integration

### 4. Resource & Information Access
- **Church Resources**:
  - Access service guidelines and instructions
  - View training materials and documentation
  - Download relevant forms and documents
  - Access church announcements and communications

- **Educational Content**:
  - View spiritual development materials
  - Access teaching resources
  - Participate in online learning modules
  - Review church doctrine and teachings

- **Communication Hub**:
  - View messages from church leadership
  - Access team communication channels
  - Receive important church notifications
  - Participate in servant forums

### 5. Role Management
- **Role Flexibility**:
  - View current role assignments
  - Request additional role responsibilities
  - Switch between different service areas
  - Explore new service opportunities

- **Skill Development**:
  - Identify skill gaps for service improvement
  - Access training opportunities
  - Track skill development progress
  - Request mentorship from experienced servants

## User Interface Features

### Service Dashboard
- **Today's Overview**: Current day tasks and activities
- **Points Summary**: Current balance and recent activity
- **Upcoming Schedule**: Next 7 days of commitments
- **Quick Actions**: Access to common tasks
- **Recent Activity**: Latest completed tasks and points earned

### Task Management Interface
- **Task Cards**: Visual representation of each task
- **Status Indicators**: Clear visual cues for task status
- **Priority Marking**: Visual priority indicators
- **Progress Tracking**: Task completion progress bars
- **Quick Actions**: Fast access to common task operations

### Points & Achievements Display
- **Point Counter**: Visual point balance with animations
- **Achievement Showcase**: Earned badges and recognitions
- **Progress Charts**: Visual representation of service growth
- **Leaderboard**: Friendly competition among servants
- **Redemption Center**: Points exchange options

## Workflow Examples

### Completing Assigned Tasks
1. Navigate to Dashboard → Today's Tasks
2. Select task from the list
3. Review task details and requirements
4. Complete the task according to instructions
5. Return to system to mark as completed
6. Add completion notes and observations
7. Submit for review and earn points

### Planning Service Schedule
1. Navigate to Schedule → Calendar View
2. Review upcoming church events and activities
3. Select events to participate in
4. Register for selected activities
5. Set personal availability preferences
6. Receive confirmation and reminders

### Tracking Service Progress
1. Navigate to Service History
2. Review completed tasks by category
3. Analyze point-earning patterns
4. Identify areas for improvement
5. Plan future service commitments
6. Request additional responsibilities

## Permissions & Restrictions

### Makhdoum Can:
- View and manage assigned service tasks
- Track personal points and service history
- Participate in church events and activities
- Access church resources and educational content
- Communicate with church leadership and team members

### Makhdoum Cannot:
- Access tasks assigned to other servants without permission
- Modify church administrative settings
- View sensitive church financial information
- Assign tasks to other servants
- Access other users' private information
